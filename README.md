# 2026 경기 티볼 도대회 웹앱

초등부 / 중등부 사이트를 별도로 구성했고(여고부는 4팀 토너먼트라 별도 제작 생략),
심판·운영진용 도구(`score.html`)는 두 사이트가 공유합니다.

## 폴더 구조

```
tiball/
├── shared/                 ← 초/중등부 사이트가 공통으로 쓰는 코드
│   ├── teams-elementary.js   초등부 팀 명단·조편성 (남 22팀/7조, 여 13팀/4조)
│   ├── teams-middle.js       중등부 팀 명단·조편성 (남 15팀/5조, 여 9팀/3조)
│   ├── schedule.js           전체 대회 시간표(9/5, 9/6 · A~E구장) + 결선 대진 연결정보(feedsFrom)
│   ├── standings.js          예선 순위 자동계산 (승점제 + 4팀조 예외규칙 + 운영본부 수동확정)
│   ├── firebase-config.js    ⚠️ 본인 Firebase 프로젝트 키로 교체 필요
│   ├── render.js             시간표/순위표/토너먼트 화면 렌더링 공통 로직
│   ├── style.css             공용 디자인
│   ├── favicon.ico / apple-touch-icon.png
│   └── venue/                구장 위치 조감도 이미지 3장
├── elementary/index.html   ← 초등부 사이트 (관람용)
├── middle/index.html       ← 중등부 사이트 (관람용)
└── score.html               ← 심판·운영진 도구 (초/중 공용) — 탭 2개
    ├─ "스코어 입력" 탭: 일자→구장→시간 선택 후 점수 입력
    └─ "순위 확정" 탭: 승점 동률 조를 운영본부가 수동으로 순서 확정
```

## 시작하기 전에 해야 할 것

1. **Firebase 프로젝트 준비**
   `shared/firebase-config.js`의 `firebaseConfig` 값을 본인 프로젝트 키로 바꿔주세요.
   기존에 쓰시던 프로젝트(dodgeball-efbff 등)를 재사용해도 되고, 새로 만들어도 됩니다.
   Realtime Database 규칙은 대회 기간 한정으로 아래처럼 열어두시면 됩니다(대회 종료 후 잠그시길 권장):
   ```json
   { "rules": { ".read": true, ".write": true } }
   ```

2. **배포**
   GitHub Pages에 이 폴더 전체를 그대로 올리면
   - `https://[아이디].github.io/[저장소명]/elementary/` → 초등부 사이트
   - `https://[아이디].github.io/[저장소명]/middle/` → 중등부 사이트
   - `https://[아이디].github.io/[저장소명]/score.html` → 심판·운영진 도구 (스코어 입력 + 순위 확정)

   완전히 분리된 URL(도메인 자체를 따로)이 필요하시면 `elementary/`, `middle/` 폴더 각각에
   `shared/` 폴더를 복사해 넣고 별도 저장소로 나누시면 됩니다.

## 지금 버전에서 되는 것

- **시간표**: 날짜(1일차/2일차) × 구장(A~E) 매트릭스, 헤더/시간열 고정(상하좌우 스크롤),
  같은 조는 파스텔 배경색으로 구분, 종료된 경기는 승리팀 강조 표시
- **예선 순위표**: 조별 승/무/패/득실/승점 자동 집계. 일반 3팀조는 승점으로만 순위를 매기고
  동률이면 "순위 확정" 탭에서 운영본부가 수동으로 정합니다. 4팀조(남초7조·여초4조)는
  승점→최소실점→최다득점 규칙으로 자동 결정됩니다.
- **토너먼트**: 결선 대진을 실제 브래킷 다이어그램으로 표시(좌우 스크롤). 예선이 확정되면
  조1위 자리에 실제 팀명이 자동으로 채워지고, 결선 경기 결과가 쌓이면 다음 라운드까지
  자동으로 이어집니다.
- **자동 팀명 해석**: 시간표의 결선 칸과 심판용 스코어 입력 화면 모두, 예선이 확정된 조는
  "N조1위" 대신 실제 팀명이 자동으로 뜨고(동률이면 계속 "N조1위"로 표시), 심판이 결선 경기를
  열면 상대팀 이름칸에 자동으로 채워져 있어 그대로 점수만 입력하면 됩니다.
- **심판용 스코어 입력**: 일자→구장→시간 선택 후 +/− 버튼으로 점수 입력, 경기전/진행중/경기종료
  상태 전환(종료는 확인창 한 번). 입력 즉시 반영되고 별도 저장 버튼은 없습니다.
- **순위 확정(운영본부용)**: score.html의 "순위 확정" 탭에서 초/중 × 남/여 선택 후, 승점 동률인
  조를 ▲▼로 순서를 정해 "확정 저장"하면 전체 사이트에 즉시 반영됩니다.
- **구장위치 보기**: 관람용 사이트 헤더의 버튼을 누르면 화성드림파크 야구장 조감도(전체/A~C/D~E)
  모달로 표시됩니다.

## 참고: 파일을 다시 수정했는데 화면에 반영이 안 될 때

`elementary/index.html`, `middle/index.html`, `score.html`이 `shared/` 안의 `.js`, `.css` 파일을
불러올 때 `?v=10`처럼 버전 숫자를 붙여뒀어요. 브라우저가 예전 파일을 계속 캐시해서 새로 고쳐도
옛날 코드가 보이는 걸 막기 위한 장치입니다. **앞으로 `shared/` 안의 파일을 수정하실 때마다
세 HTML 파일에 있는 `?v=10`의 숫자를 하나씩 올려주세요 (다음 수정 때는 `?v=11`로). 안 올리면 일부
사용자 브라우저에서 옛날 버전이 계속 보일 수 있습니다.
