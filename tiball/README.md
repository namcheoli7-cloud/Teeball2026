# 2026 경기 티볼 도대회 웹앱

초등부 / 중등부 사이트를 별도로 구성했고(여고부는 4팀 토너먼트라 별도 제작 생략), 심판용 스코어 입력 도구는 두 사이트가 공유합니다.

## 폴더 구조

```
tiball/
├── shared/                 ← 초/중등부 사이트가 공통으로 쓰는 코드
│   ├── teams-elementary.js   초등부 팀 명단·조편성 (남 22팀/7조, 여 13팀/4조)
│   ├── teams-middle.js       중등부 팀 명단·조편성 (남 15팀/5조, 여 9팀/3조)
│   ├── schedule.js           전체 대회 시간표(9/5, 9/6 · A~E구장)
│   ├── standings.js          예선 순위 자동계산 (승점제 + 승률계산법 + 4팀조 예외규칙)
│   ├── firebase-config.js    ⚠️ 본인 Firebase 프로젝트 키로 교체 필요
│   ├── render.js             시간표/순위표/토너먼트 화면 렌더링 공통 로직
│   └── style.css             공용 디자인
├── elementary/index.html   ← 초등부 사이트
├── middle/index.html       ← 중등부 사이트
└── score.html               ← 심판·운영진용 스코어 입력 (초/중 공용)
```

## 시작하기 전에 해야 할 것

1. **Firebase 프로젝트 준비**
   `shared/firebase-config.js`의 `firebaseConfig` 값을 본인 프로젝트 키로 바꿔주세요.
   기존에 쓰시던 프로젝트(dodgeball-efbff 등)를 재사용해도 되고, 새로 만들어도 됩니다.
   Realtime Database 규칙은 대회 기간 한정으로 아래처럼 열어두시면 됩니다(대회 종료 후 잠그시길 권장):
   ```json
   { "rules": { "tiball": { ".read": true, ".write": true } } }
   ```

2. **배포**
   GitHub Pages에 이 폴더 전체를 그대로 올리면
   - `https://[아이디].github.io/[저장소명]/elementary/` → 초등부 사이트
   - `https://[아이디].github.io/[저장소명]/middle/` → 중등부 사이트
   - `https://[아이디].github.io/[저장소명]/score.html` → 심판용 스코어 입력

   완전히 분리된 URL(도메인 자체를 따로)이 필요하시면 `elementary/`, `middle/` 폴더 각각에
   `shared/` 폴더를 복사해 넣고 별도 저장소 2개로 나누시면 됩니다. (지금 구조는 코드 재사용이
   쉬운 대신 한 저장소 안의 경로로 구분되어 있어요.)

## 지금 버전에서 되는 것

- 시간표: 날짜(1일차/2일차) × 구장(A~E) 매트릭스, 예선/결선 경기 전부 반영
- 예선 순위표: 조별 승/무/패/득실/승점 자동 집계, 동률 시 승률계산법 자동 적용
  (남초 7조·여초 4조는 예외 규칙: 승점→최소실점→최다득점)
- 토너먼트: 결선 단계 경기(결선전, 4강, 결승)를 순서대로 카드로 표시
- 심판용 스코어 입력: 일자→구장→시간 선택 후 +/- 버튼으로 점수 입력, 이닝수 입력, 진행중/종료 상태
  저장 시 Firebase Realtime DB에 반영되어 초/중등부 사이트에 실시간 반영

## 다음에 다듬으면 좋은 것 (제안)

- 결선(토너먼트) 단계는 실제 진출팀이 대회 당일 확정되므로, 지금은 심판이 직접 팀 이름을
  입력하는 방식입니다. 원하시면 예선 순위표 1위가 확정되는 순간 자동으로 다음 라운드에
  팀 이름을 채워주는 로직을 추가할 수 있어요.
- 우천 등으로 인한 일정 변경을 관리자가 웹에서 바로 수정할 수 있는 간단한 관리자 화면
- 결승 라인업 인쇄용(오더지) 출력 화면
